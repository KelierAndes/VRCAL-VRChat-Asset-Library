# 下载解压与 MA 诊断实施计划

用户已要求直接落地。新下载继续沿用已验证的同商品归组；旧 UUID 目录不搬动。用户勾选已下载 ZIP 后，创建一个新的素材文件夹，各包保留独立子目录，读取这个新目录并立即入库，不全局扫描。提供下载后自动解压开关，默认关闭；回收原包默认关闭，只有本次解压、文件校验、入库全部成功后才调用系统回收站。失败保留原包和可用的解压结果。

1. `download-extract.ts`：受限 ZIP 流式解压、CRC/体积校验、路径与链接保护、取消、只清理本次输出。独立真实 ZIP 测试。
2. `download-extraction-jobs.ts`：持久化解压记录、明确输入快照、登记新目录、成功后可选回收。重启不自动重做或删除。旧下载只在用户显式勾选后采集当前身份。自动流程按本次批量下载的已确认商品组执行。
3. `BaiduDownloads`、IPC 与页面：勾选历史 ZIP、解压所选并入库、开关、进度与结果路径。离线仍可处理已下载文件。支持重试解压结果入库，重试时保留原包。
4. MA：核查自有桥及上游堆栈；精确识别菜单预览失效引用，修复日志断栈，给出中文排查。没有实际证据时不改第三方包、不宣称修好第三方异常。
5. 验证：真实临时 ZIP / 隔离资料库、失败不回收、回收失败、重启、同一素材两包、旧记录、页面实际交互；全套检查后打包并按公开预览发布流程交付。

范围：ZIP；不展开 unitypackage，不执行压缩包中的代码，不改已有工程或素材。RAR/7z 提示暂不支持应用内解压。保留原包时保留原包资料库记录，避免丢失已有标注；新解压目录是可直接预览/导入的素材条目。
