# 素材位置批量移除计划

日期：2026-10-28。用户已授权直接实现与交付，无需另行确认设计。

## 设计

在“设置与备份 → 素材位置”支持勾选多条登记位置、全选、取消勾选及“移除所选”，保留每行原有的单个“移除”。一次请求处理整批位置，验证和保存失败时不部分移除；继续遵守扫描、下载／解压、工程导入、回收等操作的互斥约束，不增加确认弹窗。

移除只取消本应用中的位置登记，停止从这些位置读取和显示素材；不删除、改名、搬动或回收磁盘文件。原资料库标注保留，重新添加原位置后可恢复使用。全部移除后保持位置列表为空，不自动补入默认目录。隐藏素材与移入系统回收站仍有各自独立的入口和作用范围。
