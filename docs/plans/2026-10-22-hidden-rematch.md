# 1.2.4 隐藏素材与强制重新匹配

用户要求：从应用隐藏不需要的条目、查看隐藏名单并恢复；把任意素材强制送回匹配确认，保留旧资料直到确认新来源；闲鱼商品可直接应用。原文件不删除、不移动、不修改。

- 在人工标注 JSON 增加 `hidden`，查询、计数和匹配队列排除隐藏记录。提供独立隐藏名单及批量恢复，扫描、重启和备份恢复保留标志。合并卡片按全部成员操作。
- 在联网记录增加 `rematchRequested`，立即进入确认页。重新检索忽略旧来源绑定的检索优先级，但不自动替换旧资料；保留排除记录。新来源确认结束该状态，来源撤回可回到重匹配前的资料。
- 右键、详情和匹配页提供入口；设置增加可搜索、可批量恢复的隐藏名单。跟随现有三语言和主题。
- 闲鱼工具栏明确显示“应用此商品”。优先读取已加载详情页的公开商品元数据；没有可验证资料时允许用户明确填写当前商品名称再应用链接，不把搜索页或登录页当作商品。保留来源撤回、会话隔离与购买操作阻止。
- 回归重点：隐藏后刷新不重现、队列取消晚到结果、恢复与标注不丢；强制重匹配保留人工来源并始终等待确认；闲鱼链接编号一致、拒绝未加载/已切换页面；隔离 GUI 验收及源文件哈希。
