## 如何找需要的工具

顶部可按名称、作者或中文用途搜索，按“用途”和“安装方式”组合筛选。例如选“预览与调试”＋“可下载并导入”，就只显示能直接导入的预览工具。VCC／ALCOM 的 29 项中包含这 6 项，统计不应相加。

GoGo Loco 使用“作者官网安装”，没有虚构的 VCC 按钮；前往官网选择版本并核对授权。Pumkin 的 GitHub 最新发布虽未设置 prerelease 标志，但版本名含 beta，因此不自动下载，保留包管理器选择稳定版的入口。

## 直接下载并导入

1. 在页面顶部选择 **直接导入的目标工程**。列表来自已经登记的工程；也可点击 **选择工程文件夹**，选择包含 `Assets`、`Packages`、`ProjectSettings` 的整个文件夹。
2. 找到需要的插件，点击 **下载并导入**。目前支持 Gesture Manager、Av3Emulator、Avatars 3.0 Manager、FACS Utilities、Animation Viewer、Blendshape Viewer。
3. 程序检查作者 GitHub 最新稳定发布，选择唯一对应的 `.unitypackage` 文件。显示文件名、版本、下载量和速度；完成后保留显示。
4. 包交给所选工程的 Unity。第一次会向该工程加入 `Assets/VRCALImportBridge` 导入助手。查看 Unity 原生导入窗口，核对后确认。
5. **等待 Unity 确认**表示还没完成。下方 **插件导入记录** 只有收到 Unity 完成回执才显示成功，有返回路径时同时显示路径。
6. 下载中可取消。已交给 Unity 的任务可在记录中取消等待，已导入文件不会因此删除。

安装不等于配置到角色。例如 Gesture Manager 需从 Unity 的 Tools 菜单打开。工程内已有 VPM 管理的同名插件时，会提示转到包管理器更新，避免并存安装。旧式 Assets 安装或自改版仍需按作者说明核对；本页不搜索这些私有内容。

## VCC／ALCOM 安装入口

1. 点击 **添加官方源到 VCC**。系统会打开已注册 `vcc:` 地址的包管理器，通常是 VCC，也可能是 ALCOM。
2. 确认作者的源；选择目标工程，找到卡片注明的包名，点击添加／应用。
3. 包管理器处理依赖和版本。唤起包管理器只是打开安装入口，本应用不会将其显示为“已安装”。

入口打不开时点击 **使用说明**，不会自动退回旧版安装器。VRCFury 按作者要求使用 VCC。

## 保存、网络和授权

- 安装包从官方 GitHub 发布附件在应用内下载，不调用 IDM。查询与下载没有发送本地路径、工程内容或私有插件名。
- 缓存在所选资料库 `plugin-downloads` 中。相同官方 SHA-256 的包经校验后复用；没有官方摘要时明确提示仅检查大小、格式及记录本地摘要。应用不解压或执行安装包，也不把 ZIP 当成 Unity 素材包。
- 断网、限流、包缺失、多候选或摘要不符会停止导入、保留说明，可稍后重试；不会退回旧版。关闭联网会停止当前下载。
- 普通资料库备份不打包第三方安装文件。更改资料库位置会迁移插件缓存。工程导入记录沿用现有记录系统。
- 第三方插件归各自作者，采用各自许可证；本应用许可不改变其授权。目录未打包分发第三方代码。插件由 Unity 在所选工程中处理。

目录定义：`src/shared/public-plugins.ts`。新增条目应核对作者、官方来源、用途、安装方式及包 ID，不能使用转载网盘或未公开代码替代官方来源。

本次在线核验：16 个官方 VPM 源正常响应，29 个包 ID 均存在，GoGo Loco 作者官网正常响应。新增的 3 个直接导入工具已通过应用同一下载通道实际下载：FACS Utilities 99,730 字节、Animation Viewer 7,276 字节、Blendshape Viewer 19,261 字节。后两项与官方 SHA-256 一致；FACS 未提供摘要，已检查长度/格式并记录本地哈希。目录数据与来源见 [来源核验记录](PUBLIC_PLUGIN_SOURCES_20261024.json)。
