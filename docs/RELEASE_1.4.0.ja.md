# 1.4.0：素材整理・一括ダウンロード・プロジェクト作業台

日付：2026-10-28 · 正式版 · Windows x64

[リリースとダウンロード](https://github.com/NecoAya/VRCAL-VRChat-Asset-Library/releases/tag/v1.4.0) · [クイックスタート](QUICK_START.ja.md) · [詳しい更新内容（中国語）](RELEASE_1.4.0.zh-CN.md)

本書は 1.4.0 正式版の更新内容と主な操作を説明します。新しい画面の一部と詳細ガイドは中国語のままで、過去のプレビュー記録はすべて翻訳していません。以下の試験機能は、正式版でもそれぞれの制限を引き継ぎます。

## ダウンロードと更新

- **単体ファイル EXE：** `VRC-Asset-Library-1.4.0-x64.exe` を起動します。公式の単体ファイル正式版は最新の安定版を確認し、ダウンロードを検証してから再起動による更新を案内します。
- **フォルダー ZIP：** `VRC-Asset-Library-1.4.0-x64-Folder.zip` をすべて展開し、中の `VRC素材库.exe` を起動します。フォルダー全体を保持してください。この版は引き続きリリースページから手動で更新します。
- **その他の ZIP：** `Source.zip` と GitHub の Source code は開発用ソースです。Guide／Offline ZIP は説明資料であり、アプリ本体ではありません。

ライブラリの整理情報をバックアップし、旧版を終了してから、既存のライブラリで新版を起動してください。保存先を尋ねられたら、既存の `VRChatAssetLibrary` フォルダーの親を選び、空のライブラリを作り直さないでください。番号の大きい旧 1.9.x／1.10.x テスト版からは手動で更新します。**更新履歴**で実行中の版を確認できます。

## 主な変更

- **素材の保存場所の登録：** 複数選択・すべて選択から登録を一括解除できます。元ファイルと注釈は保持され、元の保存場所を再追加すると引き続き使用できます。
- **百度のダウンロードと ZIP：** 選択したファイルを順にダウンロードし、完了分だけを全体の再スキャンなしで登録します。同じ商品の新しいダウンロードをまとめられます。履歴内の ZIP を選択すると、一つの新しい素材フォルダー内に ZIP ごとのサブフォルダーを作って展開できます。
- **プロジェクト作業台：** プロジェクト、依存関係の手掛かり、商品、インポート、エラーを集約します。外部の Unity プロジェクトはルートフォルダーをドラッグして追加できます。30 項目の公開プラグイン一覧から公式の配布元と導入方法を確認できます。
- **3D と任意の AI：** 軽量モデル表示とアバター・衣装の組み合わせは静止状態の参考表示です。アプリ内で千問・Kimi・DeepSeek の公式サイトを開き、自分で通常どおり送信した後、条件を満たす回答を実際の商品検索につなげられます。
- **スキャンと表紙：** 深いフォルダーと素材ファイル一覧の読み取りで、固定階層数による読み落としを解消しました。読み取りを許可された同じフォルダー内の正確な同名画像をパッケージの表紙に使い、重複画像カードを減らします。
- **出典の照合：** 出典が明確な BOOTH ダウンロードは商品・作者・分類・表紙を関連付けます。手動の出典・スキップ・除外を優先し、矛盾する出典は引き続き確認が必要です。
- **起動と配布形式：** ウェブ解析器の読み込みを遅らせ、クラウド項目がない場合はライブラリ全体の関連付けを省きます。実行時依存ライブラリのライセンス全文とフォルダー版を同梱します。
- **保存と診断：** ライブラリ・バックアップ・素材フォルダーの境界と排他的な保存を強化しました。閑魚ウィンドウを閉じた後の処理、最近のリンクの日付、要確認状態を改善しました。Unity の破棄済みオブジェクトのメッセージに続くスタックを保持し、MA メニュープレビューの無効な参照に中国語の案内を表示します。第三者プラグインの例外は実プロジェクトでは未再現です。

## 新しい操作の要点

**設定とバックアップ → 素材位置** でパスにチェックを付けるか **全选**（すべて選択）を押し、**移除所选（N）**（選択した登録を解除）を実行します。**取消勾选** は選択を解除するだけです。すべての登録を解除すると一覧は空のままになり、**添加素材文件夹** で自分のフォルダーを追加できます。ファイルの削除・改名・移動・ゴミ箱への移動は行いません。[詳しい手順と再登録（中国語）](SOURCE_LOCATIONS.zh-CN.md)。

百度ページの **下载记录**（ダウンロード履歴）で、同じ素材のモデル ZIP とマテリアル ZIP を選び、**解压所选并入库**（選択した ZIP を展開して登録）を押します。進捗と出力は **解压记录**（展開履歴）で確認できます。新しいフォルダーに展開し、展開だけでは元のダウンロードを移動しません。

**ZIP の自動展開**と**展開・登録成功後に元 ZIP をゴミ箱へ移動**は別々の設定で、どちらも初期状態では無効です。元 ZIP を残す場合は後者を無効のままにしてください。有効時も、展開・検証・登録が成功した後だけゴミ箱への移動を試みます。対応するのは ZIP のみで、Unity へのインポートは行いません。[操作と失敗時の復旧（中国語）](DOWNLOADS.zh-CN.md)。

## 機能の制限

- スキャンと整理は元ファイルを変更せずに読み取ります。明示的な展開は新しいフォルダーへ、明示的なインポートは選択した Unity プロジェクトへ書き込みます。
- 3D は Unity のマテリアル・MA・物理を再現せず、自動試着・体型適合・めり込み修正は提供しません。実アバターの MA／SDK、実アカウントの納品、AI の効果はそれぞれ別途検証が必要です。
- MA 診断はこのアプリのログ解釈と提案を改善するもので、外部プラグインの不具合修正を証明するものではありません。[MA 診断ガイド（中国語）](MA_MENU_PREVIEW_DIAGNOSTICS.zh-CN.md)。
- 閑魚は読み込み済みの公式アカウントページのみを対象とし、プラットフォームのウィンドウを閉じた後の独立したバックグラウンド検出は提供しません。ウェブ AI は自動送信せず、ログインや認証を回避しません。
