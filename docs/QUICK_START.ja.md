# VRC 素材ライブラリ 1.2.0

**初の正式版:** 1.0.0 から正式版の番号を開始します。以前の 1.9.x・1.10.x はテスト版です。テスト版の方が番号が大きいため、内蔵更新では 1.0.0 が表示されません。旧版を終了し、正式版 EXE を一度だけ手動でダウンロードして起動してください。既存の資料庫を引き継ぎ、保存先を尋ねられた場合は既存の `VRChatAssetLibrary` フォルダーの親を選択します。以後の正式版は内蔵更新を利用できます。旧テスト版の実行ファイルは公開を終了し、ソースの履歴は残しています。

VRChat 素材を整理する Windows x64 向けローカルアプリです。閲覧とスキャンは読み取り専用です。明示的にインポートした場合のみ、選択した Unity プロジェクトに書き込みます。元の素材は変更しません。

1. 旧版を閉じて `VRC-Asset-Library-1.2.0-x64.exe` を起動します。既存の保存先を引き続き使用できます。初回は、素材フォルダーの外かつ C ドライブ以外に資料庫の保存先を選びます。
2. 言語選択で **日本語** を選びます。テーマでは **X ライト**、X ダーク、NASA パンク、スイス国際様式を選択できます。設定はすぐに保存されます。素材名、作者名、自分で付けたタグやメモは翻訳・変更しません。
3. **設定とバックアップ** で素材の親フォルダーを追加します。分類用の子フォルダーも再帰的に読み込みます。登録済みの子フォルダーを含む親を追加すると、登録先を親にまとめます。Unity プロジェクトは一つの項目として扱います。
4. パス横の削除ボタンは、読み込みと表示の対象から外す操作です。元ファイルや注釈は削除しません。同じパスを再追加すると元の項目を利用できます。資料庫とバックアップは読み込み対象の外に保存してください。親フォルダーに資料庫が含まれる場合は、先に資料庫の保存先を変更します。
5. オンライン補完を有効にすると、BOOTH の商品情報や画像を検索します。曖昧な結果は確認が必要です。自動検索で見つからない場合も、内蔵 BOOTH ブラウザーで検索し、商品ページの適用ボタンから関連付けられます。間違えた出典の確定は取り消せます。
6. **設定とバックアップ** で更新の確認・ダウンロード・再起動ができます。自動更新は、素材フォルダーの外に保存した公式ポータブル EXE に対応します。GitHub が公開する SHA-256 でダウンロードを検証します。旧版から本版への初回更新だけは手動ダウンロードが必要です。

Ctrl + マウスホイールで表示サイズを変更できます。右クリックメニューから元の場所を開けます。通常のバックアップには整理情報と画像を保存し、ログイン情報や元の素材ファイルは含めません。ログイン情報はローカルで保持し、資料庫の保存先変更時に引き継ぎます。有効期限切れや失効時は再ログインが必要です。

素材を利用する前に、BOOTH の作者ページで出典と利用条件を確認してください。

## プロジェクト内ファイルとインポート

プロジェクトを選び「プロジェクト内のファイルを見る」で実際の Assets を閲覧します。商品と未一致のファイルも表示し、右クリックで場所やパスを確認できます。依存パッケージと Unity バージョンは別のタブで表示します。ファイルの存在や名前の一致だけでは、シーンで使われている証明にはなりません。

素材を右クリックして「プロジェクトにインポート」、またはプロジェクト詳細からローカル素材のインポートを開きます。対象プロジェクトと具体的なファイル・対応版を選び、プレビューを確認して実行してください。

- **unitypackage:** 初回は対象の `Assets/VRCALImportBridge/Editor` にオープンソースの Editor ヘルパーを配置します。リクエストと結果は同プロジェクトの `Library/VRCALImportBridge` に保存します。Unity 標準の確認画面で内容を選んでインポートします。バージョンが完全一致するエディターだけ自動起動します。見つからない場合は一致する Unity.exe を選択するか、手動でプロジェクトを開いてください。コンパイルエラーや自動更新の無効化で待機する場合があります。送信済みは完了を意味しません。受け取り前のリクエストはこちらで、受け取り後は Unity の画面でキャンセルします。
- **通常ファイル・フォルダー:** 元の階層と `.meta` を保ち、`Assets/VRCAL_Imports` 内の新規フォルダーにコピーします。既存ファイルは上書きしません。Assets・Packages・パッケージキャッシュの GUID が衝突する場合は停止します。コピー完了は、Unity のコンパイルや依存関係の処理完了とは異なります。
- **ZIP/RAR/7z:** ご自身で展開してから素材庫を更新してください。自動展開しません。リンク、元素材と対象の重複、処理中の元ファイル変更は拒否します。

履歴は再起動と資料庫の移行後も保持し、成功後は既存のメモや手動関連を残して素材を関連付けます。通常の資料庫バックアップに工程ファイルやヘルパーは含まれません。コピー後の記録保存が一時的に失敗した場合は再実行せず、結果ファイルによる復旧を待ってください。シェーダー・SDK などの不足は Unity で確認してください。

「貢献者とコミュニティ」の「グループチャットに参加」で QQ グループの QR コードを表示し、番号 **1002563035** をコピーできます。おしゃべり・アップデートのリクエスト・不具合報告にご利用ください。QR コードはオフラインでも表示できます。

## 1.2.0 の更新内容

- **プロジェクト内の商品:** 詳細・ファイル閲覧・右クリックから Assets を読み取り専用で調べ、商品 ID・Prefab・説明内のリンク・完了済みインポート記録を表示します。根拠とパスを確認し、個別／一括登録から BOOTH 照合につなげられます。名前だけの一致は未確認の手掛かりとして扱います。
- **任意の MA 装着:** インポート後に Unity でアバターと Prefab を選択します。対応版 Modular Avatar が必要で、アバター階層の最後の子として装着し、1 回の Undo に対応します。確認後のシーン保存は手動です。Assets の実際の場所と、メタデータによる変更候補は区別します。Unity ヘルパーの中国語 UI と既知バージョンの更新にも対応します。
- **百度網盤（試験）:** 独立した公式サイトのセッションでログインし、選んだ親フォルダーとサブフォルダーを読み取ります。一時停止・再開・再試行とローカル素材との関連付けに対応し、アーカイブはダウンロード・展開しません。認証やサイト変更で中断する場合があります。未取得の項目を削除しません。
- **更新履歴:** サイドバー・設定からオフラインで表示できます。[GitHub Releases](https://github.com/NecoAya/VRCAL-VRChat-Asset-Library/releases) に正式版の説明・プログラム・ソース・ハッシュを公開し、[CHANGELOG.md](../CHANGELOG.md) にも記録します。アプリ内更新は最新の正式 Release を参照します。

更新時は既存の資料庫を引き継いでください。1.2.0-local.* の試験版からは、一度正式版 EXE を手動で起動してください。詳しい動作と検証範囲は [工程・クラウドの説明（中国語）](LOCAL-CLOUD-MA.md) を参照してください。
