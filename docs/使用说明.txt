VRChat本地素材管理器 1.0.0 · Windows x64

正式版与测试版升级

1.0.0 是首次正式发布，之前的 1.9.x、1.10.x 都是测试版。编号重新起算，因此旧测试版不会通过内置更新自动切换到较小编号的正式版。请退出旧版，手动下载并运行 VRC-Asset-Library-1.0.0-x64.exe 一次；后续正式版可正常内置更新。原资料库和人工标注继续沿用。如果询问保存位置，请选择原 VRChatAssetLibrary 文件夹的上级目录，不要另建空资料库。旧测试版的程序附件已撤下，源码历史保留。

使用入门

- 支持简体中文、日本語和 English。主界面与“设置与备份”可即时切换，素材名称、作者、路径、人工标签与备注保留原文。
- 提供 X 暗色、X 亮色、NASA 朋克、瑞士国际主义四套主题。主题与语言分别保存，重启、备份恢复与资料库迁移保留有效选择。
- 可添加素材母目录，递归扫描分类子目录；新增母目录会替换已登记的子路径。移除路径只停用扫描和显示，不删除原文件或标注，重新添加后可继续使用。
- 资料库与备份必须放在扫描母目录之外。母目录含有现用资料库时，先在“资料库数据 → 更改保存位置”迁移资料库，无需移动原素材。
- “设置与备份 → 应用更新”可检查新版、下载并校验 SHA-256，完成后确认重启更新。自动替换支持位于素材目录之外的官方便携 EXE；失败时保留原程序并可前往发布页手动更新。首次从旧版升级到本版需手动下载一次。

商品匹配与整理

- 编号优先：纯 BOOTH 编号、压缩包和版本／副本后缀会先核对对应商品；日期、版本号及编号冲突会保守处理。手动来源可输入 1–12 位合法编号。
- 名称匹配支持作者前缀、作者内部短横线，以及本商品明确列出的英日名称。连写名称仅使用已经核实的作者别名，结果有歧义仍待确认。
- 分类采用人工分类、本商品 BOOTH 最细分类、标题／用途、标签、本地线索的顺序。搜索卡片的商品编号必须完全相同；服装内的 PNG、Textures、Materials 不会把整套衣装变成贴图。详情的“查看名称与分类依据”可查看保存的证据。旧自动记录开启联网后按队列渐进补正，失败保留已有资料。
- 单一素材的同名／编号包装层在刷新扫描后合并为一张卡。原文件、各层路径与成员标注保留；详情与匹配确认里展开本地路径，可右键定位。多商品、编号或作者冲突、工程及目录链接保持独立。

旧版自动待确认条目会在开启联网并恢复补全后按新规则复评；仍有歧义时保留可用候选。完成标记随重启和备份保存，网络失败或暂停不会算作已完成，也不会清空旧候选。人工来源、排除和跳过继续优先。

升级：关闭旧版，运行 `VRC-Asset-Library-1.0.0-x64.exe`，沿用已选择的资料库。点击“刷新素材”补齐包装关系，开启联网后补正旧自动资料。人工来源、分类、排除和跳过优先。四套主题、彩色封面、Ctrl＋滚轮和稳定的确认顺序继续保留。


界面语言与四套主题
主界面右上角“界面主题”可随时选择“X 暗色”“X 亮色”“NASA 朋克”或“瑞士国际主义”；“设置与备份”也有四套主题的预览和选择。
选择任意主题后，重启与更改资料库保存位置时都会保留有效选择。新版备份保存主题与语言，恢复后不会反复重置主题。
X 暗色使用 #000000 纯黑背景、#16181C 深灰面板、#2F3336 分隔线、#E7E9EA 正文、#71767B 次要文字和 #1D9BF0 蓝色重点，配合圆角控件与 Inter 常规／粗体。
X 亮色沿用 X 暗色的导航与图库布局，使用白底、浅灰面板和蓝色强调。
NASA 朋克以暖灰航天设备为基础，包含细线面板、铆钉铭牌、四色复古条、功能编号、黑白警示斜纹和轻微磨损、手写提醒；主要操作用红色强调。
瑞士国际主义使用实际 12 栏网格、大标题与小正文、Inter 常规／粗体、左对齐和不对称留白，界面配色只用黑、米白与强调红。
四套主题中的素材封面、匹配候选、详情、悬浮介绍和工程预览均保留图片本色。远程 BOOTH 网页保留网站自身样式，商品预览与 BOOTH 浏览器的本地工具栏跟随主题与语言。
主界面和本地工具栏在窗口显示前读取已保存的主题与语言，避免先闪出浅色界面再切换。
Ctrl+滚轮调整整界面缩放；主题、语言、内容密度与缩放分别设置。
Inter 400 常规与 700 粗体已随程序离线提供；完整源码中的 assets/fonts/Inter-OFL.txt 附有 OFL 字体授权。

来源撤回、BOOTH 搜索与账号下载
确认点错后，可在顶部或匹配确认页点击“撤回来源”，恢复确认前的商品信息、封面与候选；未完成补全任务也会取消。
后来修改的人工标题、分类、标签、备注、收藏、截图与关联保留。来源撤回跨重启保存，与“撤销整理”分别操作。
每个确认行新增 BOOTH 搜索框，可搜商品名、编号或网址；打开商品后点工具栏“应用此商品”，明确绑定当前本地素材。也能随时撤回。
Kaguya,Mizuki,Rurune_Veil_Breeze_v.1.1 这种前置多个适配名的文件名会提取 Veil Breeze；Materialpack 只作补充检索线索，不自动当作完整商品。
6986518 Lilith Vice 中商品编号优先；外层 d1548 内浅层子目录也会提供此线索。多个商品包或编号仍需确认。

左侧“BOOTH 账号与下载”可打开登录、喜欢的商品、Gift、已购资料库。账号内容在内置浏览器中浏览。
首次登录由你在 BOOTH/Pixiv 官方页面完成，验证码或账号验证按网页提示操作；以后保留登录会话，服务器失效时需要重新登录。
会话保存在你选择的资料库位置。临时 Cookie 使用 Windows 加密保存，不保存明文密码；资料库备份不含登录凭证。
“清除登录会话”会关掉账号网页并清除本机登录状态，已下载文件和素材标注保留。
先选择下载保存目录（C盘之外、原素材目录之外），再在 BOOTH 网页点击下载。每个下载放入独立新子目录，不覆盖同名旧文件。
下载进度、速度和文件名持续显示；完成记录保留，可定位文件或查看已导入素材。多个网页下载可以同时进行。
完成后自动只读登记素材，不自动解压、运行或导入 Unity；来源能明确时保存商品链接，不能明确时按文件名检索。
文件已保存但登记失败时点击“重试导入”。关闭程序或网络中断后未完成的文件需回 BOOTH 重新点击下载。
下载原文件不包含在整理资料备份中，仍按保存位置引用；请自行保留下载文件。

启动与保存位置
先退出旧版窗口，再双击 VRC-Asset-Library-1.0.0-x64.exe。
首次启动选择 C 盘以外的资料库上级目录，程序在其中创建 VRChatAssetLibrary。
旧版数据库、封面和待补全任务会复制并校验到新位置；旧资料保留，未自动清理 C 盘旧文件。
“设置与备份”里可以更改资料库位置，也可以独立选择备份位置。
备份导出和恢复前的自动备份都使用用户所选位置，不默认放入 C 盘。
实际数据库、封面、网页缓存和浏览会话数据写入所选位置；程序旁和当前 Windows 账户同时保存小型位置记录，更换程序文件夹后继续使用所选资料库。
选择资料库位置时不能放入素材目录内，也不会覆盖目标目录中已有的资料库。

浏览与缩放
鞋子、袜子统一归入“服装”，不再单独列“鞋子”；旧鞋类记录及保存的筛选兼容到服装。
服装误归饰品或未分类的自动判断已调整，Cozy Cutie、Meira 这类名称不直接写“服装”的商品，会进一步核对商品自身的穿着、上衣、下装和衣装说明。
联网类别为“未分类”时会继续使用有效的本地类别线索。启动时用已有缓存自动离线重算自动分类，无需重新联网，也无需重新扫描原文件。
人工指定的分类仍优先保留，包括你明确选择的“未分类”或“饰品”；仅描述“适用于某件服装”时，不会据此把饰品误判为服装。
左侧切换类别、收藏和工程；上方搜索及筛选。本地适配筛选只使用已找到的本地线索和人工确认。
可切换网格和列表，单独选择内容密度以及完整显示／裁切封面；这些设置会保存。
Ctrl 点击增减选择，Shift 点击按当前筛选顺序连续多选，方向键浏览，Ctrl+A 选择已显示的素材，Ctrl+F 搜索，Esc 清除选择。
切换布局保留选择，返回原筛选保留浏览位置；换到其他筛选不会批量修改隐藏的旧选择。
按住 Ctrl，滚动鼠标滚轮放大或缩小界面。设置中可调整比例、恢复 100%。
鼠标停留在素材卡片上，会出现介绍浮窗：已有商品介绍、用途分类、本地适配及来源摘要。
没有商品介绍时明确显示尚未获取，应用不会编造具体功能。

同素材合并与适配对照
同一商品的文件夹、重复包装层、版本和压缩包集中展示；原文件不会被移动、删除或改名。
不同商品编号、作者冲突的内容不会自动混合。成员文件列表仍可查看每一份本地路径和原标注。
通过本地子目录、文件名、压缩包文件名及 ZIP 包内名称判断有哪些适配模型。
适配对照里，彩色带勾项有本地线索；BOOTH 支持但未找到本地证据的项用灰色显示。
名称不完整、加密归档、读取限制等都会影响识别，所以灰色不等于确定缺失或已验证不兼容。
展开“本地识别依据”可查看对应文件；也可手动确认适配模型。

匹配与按图确认
Material、PSD、VT_Material&PSD、新建文件夹这类辅助目录不再单独显示或参与匹配；原文件、旧记录和标注保留。
容器中有独立名称的真正素材继续显示；裸辅助材质包和松散 PSD/贴图不会成为替代候选。
确认页可选择文件修改时间或首次入库时间的最新／最早顺序；设置会保存。时间依据在每行显示，不等同购买或下载时间。
每确认或跳过一条，只移除这一条；其他条目保持顺序和滚动位置，不自动补行。需要重新读取时点击“刷新待确认列表”。
确认页的本地信息区可右键打开所在文件夹、复制路径；展开本地文件后，每个成员也可独立定位。
每行可输入商品编号或 HTTPS 商品网址，点击“读取并采用来源”手动登记。
“跳过自动匹配”会将素材转到左侧“手动归类”，不再出现在匹配确认页或自动检索；原资料保留。
手动归类页面可继续标注，也可返回自动匹配。直接指定商品来源仍可读取该链接。
文件名里的商品编号优先读取，不再被说明中的模型、工具网址挤掉；找不到编号时继续按名称搜索。
识别重复标题、促销装饰、版本、适配标签和 (1) 等副本后缀；商品名称本身的区别会保留。
ZAICRIFICE_Y2K_Hair_Clips 这类“作者_商品名”会补充不带作者前缀的检索，并用实际作者或店铺别名核对。
文件夹内浅层包名和目录名也会成为线索；有多个商品编号或同名冲突时仍需要确认，不随意认定。
无搜索结果页中的推荐商品不再进入候选；匹配依据会显示编号、名称、链接或人工来源。
可排除错误候选，重启和重试后仍记住；“恢复排除”让它们重新参与检索。
手动确认或粘贴的来源链接优先，组内成员采用同一人工来源；刷新不会悄悄更换它。
页面下架、网页失败或封面下载失败后，已有标题、封面和人工信息仍保留。
左侧“匹配确认”打开专门页面，每行一个本地素材，候选商品图横排展示，每页 10 行。
点击候选封面或“使用此商品”确认；确认后该素材从待确认页移除，封面与商品信息继续保存。
本页候选封面会加入下载队列，也可点“加载本页预览图”重试；只读取公开商品封面。
“预览网页”打开应用自带的 Chromium 窗口，可看完整封面和介绍，不需要另装 Chrome。
在预览工具栏点击“确认这一商品”也可采用原候选；跳到其他商品页面时不能误确认原候选。
原候选预览可以返回、前进和重载；仅浏览公开商品网页，不下载素材或登录。账号登录和下载请使用“BOOTH 账号与下载”；应用不绕过网站验证。
更新后先“刷新素材”获取浅层包名线索，再从“在线补全”右侧下拉菜单选择“重试未匹配”。
全库重试跳过已匹配商品、缺失素材与工程；选中卡片点击“在线补全”则重新核对所选成员。

网络、速度与代理
下载面板会保留最近完成项、累计下载量、历史峰值和上次下载轨迹，短下载完成后也能看清发生了什么。
点击“下载面板”查看大图、正在并行处理的任务和可筛选下载历史；最近 100 条记录及统计跨重启保留。
空闲时当前速度为零，图表保留上次最后一段 60 秒下载轨迹；历史峰值表示曾经观察到的最高速度，不是当前速度。
默认并行补全 3 个素材，可在面板或设置中改为 1～6。
BOOTH 及其子域名的请求启动间隔至少三秒；封面 CDN 和不同网站独立调度，不会靠增加并发绕过限流。
遇到 429 会按网站要求等待；暂停或退出会保存所有未完成任务。
补全过程显示当前素材、实际访问或下载的链接，以及商品检索、商品网页、封面图片等类型。
下载速度和字节数来自本应用实际接收的响应正文；短下载也保留完成记录与平均速度。平均速度按请求开始到最后一块正文的实测时间计算。
累计量包括失败或中断请求已经收到的正文；同一共享请求只计一次。缓存读取标为缓存，下载速度为零，也不增加累计下载量。
当前补全使用 GET 请求，不上传素材，应用上传正文速度为零；请求头和网络协议仍会发送数据，这些未计入面板。这里不是整台电脑的总网卡流量。
代理状态读取系统配置；可手动检查连接，也会根据实际下载更新。不会更改系统代理。
面板会显示网站访问受限、连接检测失败或超时；这些状态不能单独证明代理失联。仅有代理配置也不等于已经证明连接正常。

编辑、右键与备份
点击卡片编辑名称、分类、标签和备注，点击保存。只保存真正改动的字段。
勾选多张卡片或按 Ctrl 点击，可批量标签和分类。
批量标签可分别添加和移除；“撤销标注”恢复这次修改，保留之后的联网结果。
标签管理支持合并名称、设置搜索别名，减少相近标签重复。
“集合”只保存关联，一个素材可放进多个集合；移出或删除集合不会删除磁盘上的素材。
“保存筛选”创建智能视图，符合条件的新素材会自动出现。
右键支持打开所在文件夹、复制路径、商品页、收藏、标签、分类、关联、封面和重新匹配。
本地成员行也有右键菜单，可定位到具体压缩包或目录。
工程可标记制作中或已完成，添加截图；文件列表只读查看，包不会自动解压，工程不会自动导入。
选择工程后，右侧“工程内素材”显示自动找到的素材和人工关联；点击素材可看详情并返回工程。
自动核对使用工程内目录、Prefab 和模型的名称，并展示具体路径；同名有歧义时标为待核对，不自动认定。
“手动关联素材”可补充关联，“刷新工程素材”重新检查新导入或改名的工程内容。
工程检查有时间和数量上限，遇到限制、无法访问或未覆盖范围会提示；名称线索不代表已验证全部实际依赖。
备份包含整理信息和封面，不包含原素材；恢复前先备份，再合并恢复。
新版备份还包含集合、标签别名、视图偏好及需恢复的异常记录；元数据和封面经过完整性校验才导入。
新版备份也包含界面主题与语言选择；恢复后不会反复重置主题。

搜索和格式范围
多个关键词默认都要匹配；准确 BOOTH 编号优先，结果提供命中名称、作者、标签、备注或介绍的依据。
搜索支持中文、日文短词和中英混排；首次建立大型索引分批进行，期间仍可按已有字段查询。
本版整理 VRChat 素材与图片，不提供视觉语义识别、云端 AI 或完整 Unity 工程依赖导出。
ZIP / Unitypackage 在独立进程中只读解析，设定条目、数据量、时间及堆内存上限；可暂停扫描。
RAR / 7z 只通过系统支持的格式列目录，不能读取时给出说明，不自动解压。
独立图片可复制到资料库作预览；工程截图仍由用户选择，原图不改动。
