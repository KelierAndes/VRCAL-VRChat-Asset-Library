# VRChat本地素材管理器 v1.4.0-preview.8

修复闲鱼关闭崩溃及会拦截聊天连接的规则，增加免 API 密钥的网页 AI 辅助找素材，移除三条示例按钮。

## 闲鱼连接与窗口

- 修复消息窗口或站内子窗口关闭后访问已销毁 `BrowserWindow.webContents`，导致主进程弹出 `Object has been destroyed` 的问题。
- 官方公开脚本使用加密 WebSocket，旧规则只接受 HTTPS，会拦截该连接。本版只为已核实的两个精确主机放行正常 WSS 握手；仍限制资源类型、方法、端口和公共 DNS，不放宽页面导航。[取证与限制](XIANYU_CONNECTION_CHECK.zh-CN.md)。
- 连接失败／断开时窗口标题提示按 **Ctrl＋R** 重试。加载失败、渲染进程退出、断网或迟到回调不会把错误页恢复成可采用商品状态。
- 本版修复已核实的客户端问题；网络、代理、账号验证或网站故障仍可能导致断连，页面打开不代表聊天已经连接。

## AI 找素材

- 已内置 VRChat 专用检索提示词，区分品类、风格、颜色和细节，为 BOOTH 整理简短日文／英文词，为闲鱼整理中文词。API 和网页辅助共用，可在页面展开查看。
- 移除原来的三条示例按钮，直接输入你想找的内容。
- 保留免密钥的本地关键词搜索；这是有限词语规则，与真正 AI 分开显示。
- 新增 **使用网页 AI（免 API 密钥）**：复制内置提示词与当前需求，打开千问／Kimi／DeepSeek 官网，正常登录、粘贴并发送；把完整 JSON 回答复制回来，点击 **使用回答搜索商品**。
- 网页方式不调用 API，不计入 API 调用次数；需要用户在官网操作。网页登录、额度、验证和服务可用性由官网决定，不承诺永久免费或静默后台调用。
- 回答只提供有界检索词，实际商品仍来自站内搜索；拒绝商品列表、任意网址或额外字段。错误回答保留上一次结果，原文不写入资料库。[操作说明](AI_DISCOVERY.zh-CN.md)。

## 升级与验证

退出旧程序后运行 `VRC-Asset-Library-1.4.0-preview.8-x64.exe`，继续使用原资料库，无需重建标注。此版为公开预览，需手动下载，不进入稳定更新通道；之前 BOOTH 下载关联修复及其他功能继续保留。

本轮使用严格窗口 mock、真实 Electron 隔离窗口、合成官方页面和模拟商品响应，验证关闭／加载失败／断网、准入规则、免密钥检索、错误回答保护及界面缩放。没有读取真实聊天或调用付费 AI，也不将模拟结果称为真实闲鱼账号聊天已通过。实际免安装程序、完整回归及 GitHub Windows CI 的结果见附件验收记录。
