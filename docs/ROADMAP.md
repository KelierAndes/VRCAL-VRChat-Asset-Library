## 社区可以继续参与的工作

下面是可讨论和认领的方向，尚未承诺完成时间。开始较大改动前先提 Issue 明确范围，避免重复工作。

| 方向 | 可以贡献的内容 | 验收重点 |
| --- | --- | --- |
| 素材扫描范围管理 | 改善范围提示、路径冲突说明与子目录排除体验 | 仅改变索引范围；不删除素材，保留人工标注，明确旧记录怎样显示 |
| 匹配与分类样例 | 公开商品链接、异常文件名、精简网页样例与离线测试 | 编号、作者与本商品名称相互核对；有歧义时不自动认定 |
| 贡献者入门 | 文档、安装说明、脱敏截图、常见问题 | 新用户能照着步骤完成；不要求接触个人资料库 |
| 界面与可访问性 | 键盘操作、缩放、窄窗口、对比度和文案 | 四主题、980px、200% 缩放下主要操作可用 |
| 多语言 | 校对简体中文、日语与英语，补充缺失翻译与长文字样例 | 保留素材原名与人工标注，三种语言下主要操作清楚可用 |
| 回归与兼容 | 中文／日文／表情路径、目录合并、备份与来源撤回 | 合成输入前后清单与哈希一致，人工信息重启后保留 |

文案、文档链接和已明确复现步骤的小问题可标为 `good first issue`。复杂目录合并、迁移及账号安全问题需要先熟悉相应模块，不宜仅凭任务看起来短就认定为新手任务。
