1.4.0 正式版：素材整理、批量下载与工程工作台

日期：2026-10-28。本说明汇总自上一正式版 1.3.0 以来，在 preview.5–17 中逐步提供的更新。新增功能说明以中文为准，既有英日界面继续保留。正式版包含下述有明确边界的辅助与试验功能，不代表全部功能已经完成真实场景验收。

下载与升级

1.4.0 正式版发布与下载。选择 VRC-Asset-Library-1.4.0-x64.exe 可直接运行；选择 x64-Folder.zip 则先完整解压，再运行其中的 VRC素材库.exe。Source.zip 是开发源码，不能直接作为程序启动。

单文件正式版的内置更新读取本仓库最新稳定发布（releases/latest），核对版本、官方附件和摘要后提供更新。解压目录版仍需从官方发布页手动下载新版，并完整解压到新目录运行。 公开预览版历史记录继续保留，不作为稳定更新发布。

升级前备份资料库，正常退出旧版，再运行 1.4.0，继续选择原资料库，无需重新确认商品。如果首次询问保存位置，选择原 VRChatAssetLibrary 文件夹的上级目录。旧测试系列 1.9.x／1.10.x 的编号曾高于正式版，需手动运行一次正式版；之后单文件正式版可正常检查稳定更新。

从较早正式版升级后，点击一次 刷新素材 可补齐深层目录与同名封面关系；不用搬动、重命名或重新下载原素材。刷新读取既有登记范围，保留已有商品确认与人工标注。旧版程序附件维持撤下，Git 历史及原许可继续保留。

素材整理与位置管理

  • 深层扫描：修复分类目录、压缩包和 Unity 工程因固定层数被遗漏，素材文件列表可继续读取深层子目录；达到读取数量上限明确提示。商品内部模型与贴图仍按商品整体展示，缓存和目录链接继续跳过。
  • 同名本地封面：已授权同目录中的 ZIP、RAR、7z、Unitypackage 可使用精确同名图片作封面，保留版本及适配名，支持明确的封面后缀；有歧义不猜测，不跨目录。手动添加单个文件不读取父目录，同时选择包与图片可配对；完整刷新也可在已分别登记的同目录文件来源之间配对。
  • 减少重复图片卡片：新配对图不单独建卡。旧的无人工资料配对图退出商品列表及匹配队列，原编号与备份保留；有标题、备注、标签、收藏、来源、排除、集合或关联引用的旧图继续保留。独立图片与贴图不因此隐藏。人工封面、商品封面、本地预览的优先级不变，封面配对不确认商品来源。
  • 位置批量移除：在 设置与备份 → 素材位置 勾选多个位置，或使用 全选，点击 移除所选 一次处理；单个移除入口继续提供。整批验证与保存成功后才生效，失败不部分移除。全部清空后保持为空，操作占用时先等待当前任务结束。

位置移除只取消应用登记，磁盘文件留在原处。 已有封面、备注、标签等资料保留，重新添加原位置后可恢复使用。隐藏单个素材只影响显示；确认删除或启用成功解压后回收原包，才会将对应原文件移入系统回收站。

素材目录与应用资料库、备份位置不能互相包含。保存改用独占随机临时文件并拒绝多硬链，补强队列、位置与下载任务记录。已复现的有条件硬链覆盖与目录边界缺口已经处理；用户反馈的普通扫描实际改名／移动尚未定位，不把这些加固当作该实际变化已解决的结论。

下载完成即入库与多个 ZIP 合并解压

百度分享支持勾选多个文件、全选及 下载所选，每批最多 100 个文件，依次下载，可取消后续队列。完成后只登记本次文件并更新图库，无需全局扫描；下载与入库状态分开，入库失败可重试，已完成文件保留。

明确 BOOTH 商品来源的内置下载直接关联商品编号，补全标题、作者、分类及封面，标为 BOOTH 下载关联；旧记录有明确来源时可补回。人工来源、跳过与排除优先；导航、来源冲突或无法核实下载卡片时继续待确认，不把文件名猜测当作购买证明。

BOOTH 明确商品 ID、百度同分享的保守文件族可将本次材质、适配及源文件包归入一个新目录。同名另建目录，不覆盖现有文件，不搬动历史 UUID 目录；百度分享归组不等于确认 BOOTH 商品。

历史下载记录中，可勾选同一素材的多个 ZIP，点击合并解压到一个新目录，各包放入独立子目录，完成后定点入库。另有两项保存偏好的设置，默认均关闭：

  1. 下载完成后自动解压 ZIP 并入库，按本次批量下载中的同商品组处理。
  2. 解压并入库成功后，将对应原 ZIP 移至系统回收站。

解压仅支持 ZIP，不展开 RAR、7z 或 Unitypackage，不执行包内代码，也不自动导入 Unity。保留原包时沿用其原有标注；失败保留原包，有可用解压结果时可重试入库，重试入库不回收原包。历史本地解压与入库不依赖登录或联网，需等待下载及入库空闲。

外部工程、改模工作台与 MA 排查

改模工作台记住目标工程，集中展示依赖线索、工程商品、导入历史、公开插件及报错入口。可用按钮添加扫描范围外的 Unity 工程，或直接拖入外部工程根目录；先验证并登记再读取，重复加入保留原记录并恢复可用状态，无需移动工程或先全局扫描。

同内容 Unitypackage 在预览及执行时复核重复导入。可选 MA 装配保留作者有效菜单，或创建显隐开关，装配与菜单共用一次 Unity 撤销；文件导入、装配、菜单及人工效果检查分别保存。目标工程需已安装兼容的 Modular Avatar，场景由用户检查后保存。

Unity 日志保留已销毁对象提示后的后续信息和堆栈，能识别 MA Inspector 菜单预览中的失效 Menu Installer 引用，并给出中文排查建议。本次只改善本应用的日志解析和建议，第三方异常尚未在真实工程复现，不宣称已经修复 MA 插件。

公开插件目录扩充至 30 项，列出官方来源及安装方式，6 项支持下载官方素材包后交给指定工程导入。插件依赖、适用版本和安装结果仍以作者说明及实际 Unity 工程为准。工程文件存在、人工检查勾选或模拟接口通过，均不代表 SDK 构建与游戏效果验收。

改模工作台 · 公开插件目录 · MA 菜单预览排查

无需 Unity 的轻量 3D 预览

素材详情及可配置右键菜单可打开 3D 预览，支持常见 FBX、GLB、glTF、OBJ 及部分 ZIP／Unitypackage 内容，提供旋转、平移、缩放、线框和 25%–100% 渲染比例。

添加角色看上身参考 可选择本地角色与衣服同场显示，隐藏角色部件、单独显示模型、手动调整衣服位置和尺寸，并切换五个视角。保留原始坐标与单位，两份模型分别管理资源；取消或失败保留上次成功画面，多个模型等待用户选择。

这只提供静态款式参考，不还原 Unity 着色器、预制件、MA、身体遮罩或物理，不自动合骨骼、试穿、跨角色适配或修复穿模。原文件不修改，组合模式暂停内置动画；真实商业角色的装配效果仍需在用户授权的 Unity 工程中检查。

网页 AI 找素材与待下载链接

AI 找素材 可在应用内打开千问、Kimi、DeepSeek 官方网页，无需填写 API 密钥。程序尝试填好本次需求，由用户正常登录并发送；带本次独立标记的有效稳定回答可接回真实商品搜索。保留同页复制提示词、重新填入、手工粘贴回答的回退，本地关键词规则及可选 API 搜索继续提供。

网页 AI 不自动发送聊天，不绕过登录、验证码或官网额度。AI 仅帮助整理检索词，商品结果来自真实平台网页，不作为适配、授权或购买证明。三家网页登录会话分别保存并随资料库迁移，普通备份不含凭证。真实登录、验证码、付费 API 与回答质量仍需验收，网站改版时可使用手工回退。

待下载链接页支持近期范围、去重、待核对数量和百度下载衔接。闲鱼手动检查只读当前已打开会话，后台只检查已加载的近期未读摘要，不主动打开其他会话；排除引用及草稿。相对时间标为“约”并保守估计，轮询不刷新链接年龄，没有可靠日期或提取码冲突时保持待核对。

闲鱼独立窗口关闭后的已销毁对象处理与聊天连接提示已改善；只允许核对过的官方聊天连接。真实账号从新交付到下载的完整链路仍待验收，关闭平台窗口后的独立后台发现尚未实现，不承诺无人值守获取交付。

启动、界面与许可

完整网页解析器延后至首次实际解析时加载；没有云端文件时跳过无意义的本地全库关联。解压目录运行包省去单文件每次启动前展开程序的步骤。实际耗时与内存受网页、图片、3D、磁盘与机器负载影响，不把隔离离线合成素材数据作为所有电脑的保证。
