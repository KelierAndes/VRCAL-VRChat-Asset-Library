# 1.4.0-preview.16：历史 ZIP 合并解压与 MA 菜单预览诊断

日期：2026-10-28。公开预览需手动下载，不进入稳定自动更新通道。新增文案暂为中文。

## 模型包与材质包一起解压并入库

打开百度下载页面的 **下载记录**，勾选同一素材的模型 ZIP、材质 ZIP 等已完成记录，点击 **解压所选并入库**。每次可选 1 至 100 个；单个 ZIP 也可直接点击 **解压并入库**。

程序在当前下载保存位置创建一个新素材目录，每个压缩包放入自己的子目录，避免不同包的同名文件互相覆盖。读取并登记这个新目录后，素材库直接显示结果，无需点击全局 **刷新素材**。**解压记录** 显示阶段、提示、文件数量、体积及输出目录，可点击 **打开解压目录**。

历史 UUID 下载目录和原文件留在原位置，不自动整理或搬迁。原包保留时，其原有资料库记录及人工标注继续保留；解压目录作为新素材登记。此操作不把百度分享当作已确认的 BOOTH 商品来源。

## 自动解压与回收原包由你选择

百度页面新增两项会保存的设置，初始都不勾选：

- **下载完成后自动解压 ZIP 并入库**：对之后开始的本次下载批次生效，按其中能够确认的同商品组处理；不追溯展开历史记录。
- **解压并入库成功后，将原 ZIP 移至回收站**：适用于本次手动解压或之后的自动解压。只有解压、校验和登记成功后，才尝试将参与的原 ZIP 移至系统回收站。

不勾选回收时保留原包。解压或入库失败时不自动回收；若有可用解压目录，可点击 **重试入库（保留原包）**，这一步不会回收原包。回收失败会说明哪些文件未回收，解压结果继续保留。系统回收站不等于永久删除，也不等于已经释放磁盘空间。

当前仅支持 ZIP，不展开 RAR、7z 或 Unitypackage，不执行压缩包内代码，也不自动写入 Unity 工程。这些设置属于百度下载页面，不改变 BOOTH 下载或普通扫描行为。历史 ZIP 解压和结果入库无需登录、联网，但需等待下载和入库空闲。

## MA 菜单预览报错更容易核对

本应用的 Unity 日志读取保留已销毁对象提示后的完整可用堆栈；对同时包含失效 `ModularAvatarMenuInstaller`、`MenuPreviewGUI…PushMenuInstaller` 与 `ModularAvatarMenuInstallTarget.Visit` 的调用链，显示专门的中文排查建议。迟到的堆栈可补充到原问题记录。

建议区分 Inspector 菜单预览、场景引用及构建／上传阶段，提醒先记录触发操作、备份场景并核对版本与引用。**本次只修正本应用的日志解析与建议，没有改动第三方 MA 包，也没有在真实工程复现或修复第三方异常。** 单凭这段日志不能认定角色构建或上传失败。

## 升级与验证边界

正常退出旧版，继续使用原资料库。已有下载记录可直接勾选；文件被移走、替换或无法安全核对时会停止操作，不要求为此重新下载全部素材或全局扫描。

验证使用隔离合成 ZIP、下载记录与 Unity 日志；程序交互、成品启动及打包校验以同版验收记录为准。真实账号交付、真实角色 MA／SDK 与商业素材装配仍需各自验收。
