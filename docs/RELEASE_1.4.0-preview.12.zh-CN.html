1.4.0-preview.12 · 应用内网页 AI 找素材

这次把免 API 密钥的网页 AI 衔接搬进「AI 找素材」页面，减少打开外部浏览器、来回复制回答的操作。千问、Kimi、DeepSeek 仍使用各自官方网页和账号。

怎么使用

  1. 开启应用联网，进入左侧 AI 找素材。
  2. 填写需求和可选适配角色，勾选搜索平台。
  3. 找到 官方 AI 工作区 · 免 API 密钥，选择服务商，点击 在应用内打开官方 AI。
  4. 在内嵌官网正常登录。程序尝试填好本次检索提示词；已有草稿不会被覆盖。必要时点击重新填入，或复制提示词在同一官网输入框粘贴。
  5. 在官网点击发送。只有本次标记一致、格式正确且连续读取稳定的回答，才交给商品搜索。AI 回答只提供检索词，商品仍来自真实搜索页面。
  6. 若官网结构变化或回答无法识别，使用同页折叠的粘贴回答入口继续；无需切到外部浏览器。

详细步骤、登录与排障见AI 找素材指南。

本次改进

  • 官方 AI 网页嵌入主窗口，工具栏与商品结果保留在应用界面。
  • 每次需求有独立标记；旧回答、其他需求、用户输入和不合格式的内容不能启动自动搜索。修改需求或平台、关闭工作区会使旧任务失效。
  • 三家登录会话独立保存在已选资料库中，随资料库迁移；普通备份不含这些凭证。可清除当前 AI 官网的本机登录状态。
  • 远程网页没有桌面接口；限制导航、权限和下载。切页、离线、打开设置或弹窗时隐藏网页区域，处理缩放和滚动裁剪。
  • 保留原有本地关键词搜索、API 辅助搜索和手工回答回退。
  • 修复千问因中文产品浏览器标识返回空白页，以及 Slate 占位文字被误当草稿的问题；保留真实 Chrome／Electron 标识和用户草稿。

验证范围与限制

隔离验收使用官方地址下拦截的合成网页，不发送真实账号消息，不调用付费 API。记录应区分模拟官网的自动衔接验证与真实官网账号验证；打包、重启、主题和缩放的最终结果见随版本附件的验收记录。

公开首页实机检查已确认千问和 Kimi 可显示并填入，未发送消息；DeepSeek 在自动化隔离环境出现官网“使用环境异常”提示，不绕过，普通用户环境仍待验证。三家官网登录、验证码、地区策略、额度及页面改版由官网决定；本版不承诺三家真实账号自动取回均已验收。程序不会自动点击发送，不读取完整历史对话，不尝试绕过验证。自动识别失败时保留同页操作入口。此入口目前服务于「找素材」，不同时提供免密钥分类或 Unity 报错解释。

本版是公开预览，需手动下载，不进入稳定版内置更新通道。升级前退出旧版，继续使用原资料库即可。旧版已撤下附件保持撤下。新增文案暂为中文。
