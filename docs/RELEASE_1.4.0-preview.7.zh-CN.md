# VRChat本地素材管理器 v1.4.0-preview.7

**修复“已在内置 BOOTH 下载，仍被要求手动确认商品和封面”的问题。**

## 本次更新

- 商品页和能明确核实商品的已购资料库下载，保存下载文件与商品编号的直接关联；即使文件名只有适配名、版本号或与商品名称不同，也直接读取对应商品的标题、作者、分类和封面。
- 已购资料库按本次下载对应的卡片和按钮定位商品，兼容下载按钮先取临时地址再下载的情况；下载文件编号与商品编号分开处理。
- 来源展示标为“BOOTH 下载关联”，与人工提供链接、人工确认区分，不把下载来源伪装成人工标注。
- 旧下载记录已保存明确商品来源时，启动或恢复联网补全后自动补回关联；不重新下载原文件。成功处理的记录持久化标记，后续不重复读取大包。
- 保留手动修改、跳过、排除和重新匹配的决定。多次点击混淆、编号冲突、页面导航或无法核实来源时仍待确认，不随便套用其他商品的封面。

## 使用

退出旧程序后运行 `VRC-Asset-Library-1.4.0-preview.7-x64.exe`，继续使用原资料库。在“BOOTH 账号与下载”登录、选择下载位置，从内置商品页或已购资料库下载。来源明确时，完成后自动登记并补全，无需再去匹配确认点击一次。

旧记录只有在保存了明确商品来源、对应文件仍存在且没有人工冲突时才可自动补回；先前完全没有保存来源的文件，不会仅凭文件名猜成已确认商品。旧账号页面结构或未验证的礼物／订单页面若无法提供可靠证据，仍保留待确认。

## 验证与范围

回归覆盖文件名完全不同仍自动补封面、重启与备份、旧记录修复及幂等、人工保护、跳转到其他商品、并发或过期点击、页面导航、断网与关闭。账号页面结构使用隔离夹具测试，不声称已经验证所有真实账号与所有 BOOTH 页面。

此版为公开预览，需手动下载，不进入稳定更新通道。已有 preview.5 的功能及试验范围沿用，新增文字暂为中文。附件包含对应源码、中文说明、验收记录和 SHA-256 校验；资料库和登录凭证不在发布包中。
