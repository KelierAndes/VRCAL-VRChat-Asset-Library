# 许可变更与协作方式

2026-10-24，项目决定采用 [VRCAL 社区协作许可 1.0](../LICENSE)，以公开协作、集中维护和统一发布为后续方向。这是**源码可见许可，不是标准开源许可，也不是在 GPL 上附加限制**。

## 新许可允许和限制的事情

| 行为 | 新许可中的安排 |
| --- | --- |
| 正常使用、学习源码、内部修改和测试 | 允许；私下修改不强制提交 |
| 使用软件辅助自己的有偿创作 | 允许，不把用户的作品变为项目代码 |
| 为本项目建立贡献分支、Fork、提交 PR | 允许；GitHub 平台本身授予的查看和 Fork 权利保持有效 |
| 保留版权、许可及贡献者署名 | 必须；官方维护者也须保留贡献记录 |
| 独立发布、改名打包、闭源或公开源码另发一个版本 | 未获相关权利人另行授权时，不授予这些权利；平台已有权利和旧许可另论 |
| 转售软件、套壳收费、把受限制代码做成另行发行的收费产品 | 未经必要授权不允许 |
| 提交贡献后失去自己的版权 | 不会；贡献授权仅服务于本项目按本许可维护、提供源码及统一发行 |

以上是说明，不替代 LICENSE 正文。临时分支与 PR 有利于协作；不承诺也无法通过公开仓库设置消灭所有 Fork。
