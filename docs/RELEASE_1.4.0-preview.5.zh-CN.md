# VRChat本地素材管理器 v1.4.0-preview.5

这次把此前本地预览中积累的功能一起公开，重点是让“找到素材 → 选定工程 → 导入 → 装配 → 检查效果”更连贯。也新增了轻量 3D 预览、AI 辅助和待下载链接页面。

这是**公开预览版**，请手动下载试用；不会作为稳定版内置更新推送。新增界面文字先提供中文，已有英语、日语与四套主题继续保留。

## 更新了什么

| 功能 | 这次的变化 | 从哪里开始 |
| --- | --- | --- |
| 改模工作台 | 记住目标工程，集中工程商品、依赖线索、导入记录、插件和报错处理；文件导入、角色装配、菜单与效果检查分别显示 | 侧栏“改模与工程” |
| 导入与 MA 装配 | 同工程、同内容的 Unitypackage 重复导入前提醒；装配保留作者已有的 MA 菜单，没有时可创建显隐开关；装配和菜单共用一次 Unity 撤销 | 素材导入到指定工程后，在 Unity 中选择角色和预制件 |
| 轻量 3D 预览 | 无需启动 Unity，可预览 FBX、GLB、glTF、OBJ 及部分 ZIP／Unitypackage；支持旋转、平移、缩放、线框及 25%–100% 渲染比例 | 素材详情中的 3D 预览 |
| 公开插件 | 收录 30 项公开工具，提供作者发布页、用途和安装方式；其中 6 项支持下载素材包后交给指定工程导入 | 侧栏“公开插件” |
| AI 分类建议 | 可选千问、Kimi、DeepSeek，细分衣服类型与风格，核对后接受为标签；保留人工和 BOOTH 主分类 | AI 设置与素材分类建议 |
| Unity 报错解释 | 读取核对过归属的工程输出，合并重复错误，提供本地提示和可选 AI 排查建议 | 选择工程后进入“Unity 报错” |
| AI 找素材 | 用一句话描述需求，整理检索词后从 BOOTH 或已开启的闲鱼显示真实商品、封面与来源；未配置 AI 时也有本地关键词规则 | 侧栏“AI 找素材” |
| 待下载链接 | 对应用内已加载的账号页面做近期范围识别、去重与待核对；有可靠时间证据的新记录可提示，并衔接百度下载 | 侧栏“待下载链接”，单独开启读取 |
| 页面整理 | 按“素材整理、改模与工程、查找与下载”分组；分类靠近搜索，主题与语言收进外观；空闲下载摘要更紧凑 | 左侧导航与顶部外观按钮 |

已有的 BOOTH 自动匹配、内置搜索与应用商品、来源撤回、隐藏素材、批量整理、手动拖拽入库、百度应用内下载、资料库备份继续保留。返回列表会保留筛选与浏览位置，小窗口使用导航抽屉访问全部入口。

## 怎么更新

1. 在旧程序的“设置与备份”备份资料库，并记住保存位置，然后正常退出旧程序。
2. 下载本发布的 `VRC-Asset-Library-1.4.0-preview.5-x64.exe`，直接运行，无需安装 Node.js。
3. 继续使用原资料库。如果提示选择位置，请选择已有资料库所在位置，勿新建空库来代替。
4. 从“改模工作台”选择工程，或从素材详情尝试 3D 预览。AI、账号页面读取等功能需要分别开启和配置。
5. 首次尝试装配请使用工程副本。导入与菜单完成后仍需在 Unity 检查外观、动作和菜单，并自行保存场景。

下载附件包含 Windows x64 免安装程序、与标签对应的完整源码、中文图文说明、验收记录和 SHA-256 校验清单。程序暂未签名。源码 ZIP 用于开发，直接使用请选择 EXE。

## 预览版已知边界

- **账号新链接仍在验证。** BOOTH 真实资料库条目已读取验证，但没有购买时间的条目只进入待核对，不冒充近期通知；闲鱼真实新交付和完整通知到下载流程尚未验收。当前检查应用内已加载页面，不会在平台窗口全关后独立发现未打开会话。
- **AI 需要自己的服务商密钥。** 默认关闭，分别同意发送用途后使用，可能产生服务商费用。已验证模拟服务、隐私处理和界面，尚未验证真实付费 AI 效果。不会自动购买商品，也不会直接执行报错修复建议。
- **3D 是轻量预览。** 不还原 Unity 材质、MA、物理或完整工程；不提供自动试穿、跨角色体型适配或穿模修复。
- **装配需要真实工程复核。** 原生 Unity 检查使用合成工程与 MA API 测试替身；实际商业角色、真实 MA／SDK、构建和游戏同步仍需验证。依赖文件存在不代表编译通过，效果勾选也不代表 SDK 已验证。
- Unity 输出的自动检查只在诊断页打开时针对所选工程运行。公开插件是否兼容当前工程，以作者说明和实际 Unity 检查为准。
- 扫描与整理保持只读；主动导入会写入选定工程，确认装配会修改当前场景，确认删除会移入系统回收站。不会把这些写入操作伪装成只读浏览。
