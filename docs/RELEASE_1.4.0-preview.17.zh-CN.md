# 1.4.0-preview.17：素材位置多选与批量移除

日期：2026-10-28。公开预览需手动下载，不进入稳定自动更新通道。新增文案暂为中文。

## 多个素材位置一次移除

打开 **设置与备份**，找到 **素材位置**。勾选要移除的位置，或勾选 **全选** 选择当前全部登记位置，然后点击 **移除所选（N）**，其中 N 为当前选择数量。选错时可再次点击对应复选框取消单项选择，也可用 **取消勾选** 清除全部选择。每行原有的 **移除** 继续保留，适合只处理一个位置。

多个位置以一次批量请求处理，不需要逐行点击，也不额外弹出确认窗口。全部移除后，素材位置列表保持为空，不会自动补回默认目录；需要时可重新添加自己的位置。

## 原文件与已有标注保留

**移除所选只取消本应用中的位置登记。** 这些位置不再作为当前扫描和素材展示的来源，磁盘上的文件夹、压缩包、模型、贴图和 Unity 工程留在原处，不删除、不改名、不搬动，也不移入系统回收站。

已有封面、标题、备注、标签、收藏及来源等资料库信息继续保留。重新通过 **添加素材文件夹** 或原来的手动添加方式加入原位置，读取完成后可沿用原标注；不要为了恢复而先移动或重命名原素材，也不需要到回收站还原。

位置移除、单个素材隐藏、删除并移入系统回收站是不同操作。位置移除针对整条登记来源；隐藏针对应用中的所选素材；删除会在确认后实际把对应原文件移入系统回收站。详细比较见操作指南。

## 失败与任务占用

程序先核对整批位置，再一次保存变更。任何位置无法通过验证，或保存失败时，整批不生效，避免只移除其中一部分。请查看错误提示，核对当前列表后再试。登记已提交后的补全队列保存、预览关闭异常会单独提示，位置移除仍按实际成功结果刷新；队列保存失败时暂停补全。

扫描、下载或解压、工程导入、回收等任务占用时继续遵守原有互斥约束。请先等待相关任务结束，再进行批量移除；操作进行中不要重复提交。

## 升级与验证边界

正常退出旧版，继续使用原资料库，无需重新确认商品。此版新增位置管理操作，不要求重新下载素材或移动现有文件。原有下载解压、MA 日志诊断等功能继续沿用各自的说明与验证边界。
