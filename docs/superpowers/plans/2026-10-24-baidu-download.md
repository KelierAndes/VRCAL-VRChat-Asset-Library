# 百度网盘应用内下载

目标：复用本应用的官方百度登录会话，在原生 React 页面粘贴分享文本／提取码、查看文件、选择下载目录、下载并查看持久化进度。除登录／安全验证外，不展示浏览器式网盘页面，不启动外部浏览器或下载器。

实现顺序：
1. `shared/baidu-download.ts`：严格解析官方分享链接与提取码、声明页面和任务状态。先验证混合分享文本、错误域名、多个链接和提取码冲突。
2. `main/baidu-downloads.ts`：受隔离会话约束的官方网页操作适配、文件列表和下载事件接管。文件选择必须对应已读取行；不调用未公开下载接口，不绕过网站验证／客户端限制。
3. `main/baidu-workspace.ts`：仅对指定下载视图放行下载，现有目录窗口继续只读。主进程注册受限 IPC，暂停／取消／定位使用内部任务 ID。
4. `renderer/baidu-downloads.tsx`：链接、提取码、保存目录、文件列表、进度／速度／状态和错误提示；接入云端页面。四主题适配；2026-10-24 用户要求先做中文，后续统一补齐翻译。
5. 路径校验、禁止覆盖、临时下载、重启中断标记、资料库迁移、退出登录／断网取消；测试只使用隔离资料库和合成文件。
6. 使用用户给出的分享链接做实际可用性核验。遇到登录或网站限制准确记录边界，不把合成测试冒充真实下载。真实流程未验证前不发布正式版。
