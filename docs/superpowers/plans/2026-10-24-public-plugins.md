# 公开插件目录与应用入口

用户授权：互联网和 GitHub 公开资料；不得搜索本地非公开插件。本轮不发布 GitHub、不安装到真实工程。

1. 收录 9 项官方公开插件；中文用途、适用范围、作者、官方发布/安装地址和核验日期离线可读。
2. 遵从作者安装方式。VPM 类提供固定官方源的一键唤起 VCC/ALCOM，明确还需在包管理器选择工程，不冒充已安装。
3. 官方仍提供 Unity 素材包的 Gesture Manager、Av3Emulator、Avatars 3.0 Manager，提供选择工程后“下载并导入”。仅最新稳定 GitHub Release、唯一预期文件、SHA-256/大小/gzip 校验，通过既有 Unity 原生确认和导入回执。不混入预发布 ZIP、不回退下载旧版本、不自动装配插件到角色。
4. 主进程白名单确定链接；下载存到已选资料库，源文件只读，串行、取消、进度及失败保留说明。缓存独立于素材扫描；不收集本地插件列表。不在应用代码中解压或执行下载物。
5. 回归验证错误下载、断网、域名/重定向、大小/哈希、不支持格式、缓存复用、工程导入、UI 搜索/筛选/缩放；只用隔离合成工程。

边界：VCC 唤起不等于安装成功；导入完成以 Unity 回执为准。插件安装不等于已配置进角色。普通资料库备份不打包第三方安装包；资料库迁移携带独立插件缓存。暂不自动更新已安装的插件。
