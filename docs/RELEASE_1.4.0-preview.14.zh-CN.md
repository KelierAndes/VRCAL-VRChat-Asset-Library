# 1.4.0-preview.14 · 勾选下载、完成即入库与同商品归组

本版把百度下载与素材库登记接通：下载完成后只读取、登记本次文件，直接更新图库，不触发全局扫描。新增勾选多个分享文件并依次下载；同商品材质、源文件和角色适配包可放入应用新建的同一目录。

## 新增与改进

- 百度分享列表支持勾选、全选当前文件、下载所选，每批最多 100 个文件，目录需先打开。依次使用百度正常网页下载，保留暂停、继续、取消和下载进度；可取消后续队列。
- 每个完成文件单独入库并进入原有补全队列，记录“已加入素材库”。入库失败保留文件，提供“重试入库”，无需重新下载；不自动解压或导入工程。
- BOOTH 使用明确的官方商品 ID 归组；百度使用同一分享范围及保守文件名族，识别 MAT_TEX、PSD_mdp、版本号和已知角色适配后缀。未知或冲突保持分开。
- 同名文件不覆盖、不改原名，而是另建受管目录。只影响应用新下载；已有用户素材和历史下载不会被批量搬动。
- 同受管目录的材质与适配包可合并展示，原文件、路径、记录和人工标注保留。可信 BOOTH 下载不必等封面完成才聚合；百度来源不会当作 BOOTH 商品确认。
- 新下载记录支持文件查看、工程导入选择、重启与备份恢复；迁移资料库时同时保留归组日志。文件与目录标识变化时停止写入或入库，保留文件供核对。

## 闲鱼链接提示

- 识别到链接但消息日期不完整时，明确指向“时间／提取码待核对”；提取码冲突、被最近时间范围排除也有对应说明。
- “待核对”显示数量；待下载列表为空但已有待核对链接时，给出直接入口。
- 多个已打开页面中，空页面不会覆盖另一个页面的有效识别结果。保留账号、当前会话、时间与提取码核对，不把旧链接冒充新交付。

截图形态的非 ARIA 聊天、跨元素换行链接、加密保存与重启均使用隔离合成资料验证，**不代表真实登录账号的交付全流程已经验收**。关闭平台窗口后的独立后台发现仍未完成。

## 开始使用

先正常退出旧版，再运行本版，继续使用原资料库。预览不会由稳定版内置更新自动安装；此前仍运行 preview.8 的进程不会因发布新版而自动变化。

- `x64.exe`：单文件免安装程序。
- `x64-Folder.zip`：完整解压后启动其中的 `VRC素材库.exe`，保留同目录文件；当前手动更新。
- `Source.zip`：本版对应完整源码，用于开发。

类型检查、最终回归数量、实际程序验证、合成源文件哈希与公开下载校验见随版验收附件。新增文案按维护者要求暂为中文；公开预览不进入稳定更新通道，已撤下的旧版附件继续撤下。
