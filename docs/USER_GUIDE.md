# VRC素材库 1.9.0

一个中文 Windows 桌面素材管理应用。默认只读索引 `E:\VRChat`。首次启动由用户选择 C 盘之外的资料库位置，在所选上级目录下创建 `VRChatAssetLibrary`；备份位置也独立选择。

## 1.9.0 更新与使用

- 编号优先：纯 BOOTH 编号、压缩包和版本／副本后缀会先核对对应商品；日期、版本号及编号冲突会保守处理。手动来源可输入 1–12 位合法编号。
- 名称匹配支持作者前缀、作者内部短横线，以及本商品明确列出的英日名称。连写名称仅使用已经核实的作者别名，结果有歧义仍待确认。
- 分类采用人工分类、本商品 BOOTH 最细分类、标题／用途、标签、本地线索的顺序。搜索卡片的商品编号必须完全相同；服装内的 PNG、Textures、Materials 不会把整套衣装变成贴图。详情的“查看名称与分类依据”可查看保存的证据。旧自动记录开启联网后按队列渐进补正，失败保留已有资料。
- 单一素材的同名／编号包装层在刷新扫描后合并为一张卡。原文件、各层路径与成员标注保留；详情与匹配确认里展开本地路径，可右键定位。多商品、编号或作者冲突、工程及目录链接保持独立。
- 详情与匹配确认行的“闲鱼辅助搜图”准备单张图片，可使用当前封面、本地选图或剪贴板。图片先在本机预览。当前未核实到可用的官方网页图搜入口，因此提供另存图片和手机闲鱼 App 手动搜图提示；图片是否交给闲鱼由你在 App 中决定。官网可在独立登录窗口浏览，不会自动获得图片或素材目录。
- 将闲鱼结果标题／链接粘贴回辅助窗口，整理并编辑名称，再用该名称搜索 BOOTH。闲鱼编号不会转换为 BOOTH 编号；最后仍在 BOOTH 核对并应用商品，错误确认仍可撤回。
- 闲鱼登录会话随自选资料库迁移，普通分类／封面备份不包含登录凭证。断网可继续预览、另存图片和编辑草稿；草稿仅在当前辅助窗口保留，关闭或改选素材后清空。

旧版自动待确认条目会在开启联网并恢复补全后按新规则复评；仍有歧义时保留可用候选。完成标记随重启和备份保存，网络失败或暂停不会算作已完成，也不会清空旧候选。人工来源、排除和跳过继续优先。

升级：关闭旧版，运行 `VRC-Asset-Library-1.9.0-x64.exe`，沿用已选择的资料库。点击“刷新素材”补齐包装关系，开启联网后补正旧自动资料。人工来源、分类、排除和跳过优先。三套主题、彩色封面、Ctrl＋滚轮和稳定的确认顺序继续保留。

1.8.1 去掉 X 暗色主题中素材分类和只读提示前的蓝色圆点，文字与分类数量保留。

1.8.0 新增第三套“X 暗色”主题，以纯黑背景、深灰面板和蓝色重点组织素材浏览与确认流程。每个资料库首次用新版启动时切换到 X 暗色，之后保留你选择的主题。NASA 朋克和瑞士国际主义继续提供，三套主题均保留彩色封面。服装分类规则与已有自动类别的离线校正，以及来源撤回、按适配前后缀清理商品名、确认页 BOOTH 搜索与网页应用商品、可登录的 BOOTH 账户浏览器和下载自动登记均保留。辅助目录排除、时间排序、原文件菜单、跳过与直接输入来源、稳定确认顺序和工程内素材也继续可用。

原有列表、内容密度、虚拟集合、保存筛选、连续多选、标签合并与别名、标注撤销，以及搜索和匹配依据均保留。素材仍只作引用登记；收藏、集合和截图缓存不改变原素材的位置。

## 三种界面主题

主界面右上角“界面主题”可切换“X 暗色”“NASA 朋克”和“瑞士国际主义”；“设置与备份”提供三套主题的预览和选择。

每个资料库第一次使用 1.8.0 启动时，无论是新建资料库还是从旧版升级，都会切换到 X 暗色；这次引入只进行一次。之后选择任意主题，重启仍会保留。更改资料库保存位置时也会保留主题和已完成引入的状态；新版备份恢复备份中保存的选择。已完成引入的资料库恢复旧版备份后，也不会在下次启动再次强制切回 X。

X 暗色使用 `#000000` 纯黑背景、`#16181C` 深灰面板、`#2F3336` 分隔线、`#E7E9EA` 正文、`#71767B` 次要文字和 `#1D9BF0` 蓝色重点。圆角控件、清晰边线和本地 Inter 常规／粗体区分内容与操作。

NASA 朋克使用 `#ECE5D6` 暖灰底色、设备面板与细线接缝、铆钉铭牌、四段复古彩条、小号功能编号、黑白警示斜纹及轻微磨损和手写提醒。主要按钮与重要标记采用 `#D63A2C` 红色，不使用霓虹、全息或大面积渐变。

瑞士国际主义以实际 12 栏模块网格组织界面，大标题与小正文形成对比，使用本地随附的 Inter Regular／Bold 两种字重，内容左对齐；界面配色为黑、米白与 `#DA291C` 红色，用细线和编号区分区块，不加入阴影、渐变、纹理或装饰插画。

三套主题覆盖素材网格／列表、匹配确认、详情、工程素材、BOOTH 本地页面、网络面板、设置与右键菜单。素材封面、匹配候选、详情、悬浮介绍和工程预览均保留图片本色。远程 BOOTH 商品和账户网页保留网站自身样式，商品预览与 BOOTH 浏览器的本地工具栏随主题切换。

主界面和本地浏览器工具栏会在窗口显示前读取已保存的主题，避免先闪出浅色界面再切成暗色；这一步只读取主题。Ctrl+滚轮仍用于原有的整界面缩放，主题、内容密度与缩放分别设置。

可编辑 Figma 设计：[画板一](https://www.figma.com/design/QZxQSGdMgfn5OzSj5IvvcO?node-id=2-30)、[画板二](https://www.figma.com/design/QZxQSGdMgfn5OzSj5IvvcO?node-id=2-202)。画板中的彩色示例封面由合成矢量绘制，用于演示显示效果，没有上传真实素材。

## 来源撤回与 BOOTH 账户

顶部和匹配确认页的“撤回来源”恢复最近一次商品确认前的来源、联网介绍、封面、标签、适配与候选，并取消该来源尚未完成的任务。人工标题、分类、标签、备注、收藏、截图和关联仍保留。来源历史最多保存 50 次，跨重启可用，与“撤销整理”相互独立；按钮绑定具体记录，过期按钮不会撤回较新的确认。原固定批次中的素材会回到原位置，不补入新条目。恢复资料库备份会清除此前的撤回历史。

每行 BOOTH 搜索框可填写商品名、编号或商品网址，打开共用登录会话的内置浏览器。搜索模式的工具栏明确显示当前本地素材，进入有效 BOOTH 商品页后点击“应用此商品”。这是人工确认，无需再次核对名称；页面仍要求网页有效加载，服务器错误页和搜索页不能应用。直接填写来源也属于人工确认，后续结果可撤回。

名称规则能从 `Kaguya,Mizuki,Rurune_Veil_Breeze_v.1.1.unitypackage` 提取 `Veil Breeze`，支持明确的多个前置适配名、后置适配与 `v.1.1` 版本格式。Materialpack 会补充主商品检索线索，仍需确认。`6986518 Lilith Vice` 中编号优先直读；即使外层叫 `d1548`，浅层子目录也提供编号。多个独立包、商品编号或作者冲突不会被自动合并认定为一款。

左侧“BOOTH 账号与下载”提供登录、喜欢的商品、Gift、已购资料库入口，账号内容在应用内浏览器读取。登录由用户在 BOOTH/Pixiv 官方页面完成，包括验证码或账号验证；程序不代为提交密码。Chromium 的持久会话保存在所选资料库的 `booth-session`；临时登录 Cookie 另用 Windows 系统加密保存，最长恢复 30 天，服务器仍可使登录失效。不保存明文密码，也不将 Cookie、验证参数或签名下载网址显示在列表、日志或资料库备份中。“清除登录会话”关闭账户网页并清除本机登录状态，已下载文件和素材标注保留。未实际核对登录状态时不声称已登录。

先在 BOOTH 页面选择 C 盘以外、原素材目录以外的下载保存目录，再在网页点击下载。每个任务保存到新的独立子目录，不覆盖旧文件、不自动解压、执行或导入 Unity。完成后只读登记文件名与有界包内目录，自动进入素材库；能确定当前商品时保留公开商品来源，没有依据时继续按文件名匹配。下载记录包含进度、速度、已接收字节和保存时间，完成后仍可查看、定位和打开已登记素材。文件已保存但登记失败时可“重试导入”；应用关闭导致的未完成下载需回 BOOTH 重新点击。

资料库迁移会复制并校验 BOOTH 会话与下载记录。普通资料库备份只保存整理资料与封面，不包含登录凭证或下载原文件；原下载保存位置仍按路径引用。网页账户浏览、登录及原文件下载与公开信息补全队列分别记录，不将登录表单误算成零上传的补全任务。

## 确认与工程浏览

鞋子、袜子归入“服装”，不再单独设“鞋子”。旧鞋类记录与保存的鞋类筛选映射到服装。自动分类优先核对商品标题、商品类别/标签及明确描述商品自身的说明；补充识别 Cozy Cutie、Meira 等商品对上衣、下装、穿着方式或该衣装的具体说明，修正服装误归饰品或未分类。联网类别仍为“未分类”时继续使用有效的本地类别线索，不用未知结果覆盖本地判断。启动时根据已有缓存自动离线重算自动分类，无需重新联网或扫描原文件。人工分类保持优先，包括用户明确设为“未分类”或“饰品”的记录；未知用途或只有“适用于服装”这类兼容表述时不凭猜测归衣服。

Material、PSD、VT_Material&PSD 和新建文件夹等精确辅助目录名不作为独立商品卡片；旧记录和标注仍在资料库/备份中。扫描穿过这类容器寻找有独立名称的真正素材与工程，不将松散贴图、PSD 或裸辅助材质包拆成商品候选。Material Girl、PSD Mix Pack 等完整商品名称保留；Unity 工程也不会因为名称泛化被隐藏。

匹配确认可按文件修改或首次入库时间升降序排列，设置会保存。文件修改时间来自本地文件，合并条目使用成员最新修改时间，不当作购买或下载时间。确认和跳过仅移除当前条目，本页其余素材不重新排列或自动补行；排序、筛选、翻页及“刷新待确认列表”才重新读取相应批次。

本地信息区及展开后的具体成员支持右键打开所在文件夹、复制原路径。每行可直接填写 BOOTH 商品编号或 HTTPS 网址，点击“读取并采用来源”。“跳过自动匹配”将素材转入左侧“手动归类”，保留原资料并停止自动检索；可手动整理或返回自动匹配。显式手动登记来源仍可读取该指定商品。

选择工程后，详情的“工程内素材”展示已有素材封面、工程目录/Prefab/模型文件的名称线索和人工关联。不同素材同名时标记待核对；这是本地名称核对，不等同于已经证明所有引用依赖或实际使用。扫描仅在 Assets 中进行，有数量、深度和时间上限，跳过链接及缓存；不读取素材正文上传网络，不修改工程。工程文件名改变或新导入后，可点“刷新工程素材”。手动关联会独立保存。

旧版数据库和缓存会复制、校验到新位置，原资料保留。程序旁的小型位置记录保存所选路径；目录不可写时才使用系统中的小型位置记录。实际数据库、封面及浏览会话缓存使用选定位置。

## 源文件保护

所有资料库写入经路径验证；应用没有删除、移动、重命名或修改原素材的接口。目录链接和 Unity 缓存不参与索引。联网补全只发送名称、编号等检索线索，不上传素材内容。

人工分类、标签、备注和封面优先于联网信息。同商品目录、版本和压缩包只合并展示，原始记录、路径和成员标注保留。ZIP 与 Unitypackage 在独立进程内只读解析，有时间、内存和条目上限，可取消。RAR / 7z 使用系统工具只读列目录；不能读取时显示说明。不会自动解压、导入 Unity 或修改工程。独立解析进程不是操作系统权限沙箱，不宣称能完全隔离所有解析器漏洞。

本地适配由文件与包内名称、人工确认建立证据；商品适配单独显示。灰色仅表示没有本地证据，不能当作已验证缺失。Ctrl+滚轮可缩放，设置可重置；悬停卡片显示已有商品介绍和适配摘要。

网络面板统计本应用接收的响应正文，不计请求头、TLS 开销或其他应用流量。补全使用 GET 请求，上传正文为零，素材文件不会上传；这不表示网络协议完全没有发送数据。代理检测只读取当前系统配置，结合小型连接检测与实际下载结果显示状态，不修改系统代理；网站拒绝访问或检测超时不能单独证明代理失联。

默认并发处理 3 个素材，可在下载面板或设置中选择 1–6。BOOTH 及其子域名的请求共享至少三秒的启动间隔；封面 CDN 独立调度。429 冷却与未完成任务随队列保存，同一 URL 在途请求共享，缓存写入保持原子性。
保留最近 100 条读取／下载记录、累计接收正文、观察到的历史最高速度，以及最后一段 60 秒采样。累计量包括失败或中断请求已收到的正文；缓存读取不计入累计，同一共享请求不重复计数。空闲当前速率为零，轨迹在短暂零速收尾后保留，重启后仍可查看。完成记录的平均速度按请求开始到最后一块正文的实测时间计算；历史峰值不会当作当前速度。
每个实际请求显示状态。暂停中止活动请求并保存未完成任务；迁移和恢复会先停止／暂停补全，再等待任务结束与最后保存完成。

## 匹配与确认

文件名商品编号优先于说明中的基础模型与工具链接，按商品编号合并不同语言或店铺网址。全角编号、文件名前端紧接文字的编号及明确标注的短编号可识别，日期线索避免当作商品编号；编号不可用时继续名称搜索。素材文件夹中的浅层目录和归档文件名保留为本地检索线索，多个独立商品编号不会自动认作一款。

名称规则清理版本、适配标签、促销装饰、重复标题和 Windows 副本后缀，保留商品名中有意义的型号和版本差异。`作者_商品名` 的备选检索需要商品页面作者或店铺别名核对后才能自动采用。搜索先对最多 30 个结果排序，再读取相关商品；同名或证据冲突仍进入待确认。人工信息不会被刷新覆盖。

左侧“匹配确认”每页展示 10 个素材，候选商品图按行排列；点图或“使用此商品”确认。“加载本页预览图”只缓存公开商品封面，沿用并发、暂停和缓存机制。确认页和详情的原候选“预览网页”使用应用自带 Chromium，网页与资料库接口隔离。原候选预览只确认最初选择的同一商品，不下载或登录；需要账号或自行检索其他商品时使用新的 BOOTH 浏览器。两个浏览器均不需要安装 Chrome，也不绕过网站验证。

搜索结果区与无结果页推荐区分开，推荐商品不会进入候选。匹配记录注明编号、说明链接、名称或人工确认等依据；排除的候选跨重启记忆，可手动恢复。人工指定的来源优先，组内确认同步到各份本地成员；刷新不会改绑人工来源。商品下架或封面失败会保留已有资料。

新版不自动重试整库旧结果。可选中素材点击“在线补全”，或打开其下拉菜单“重试未匹配”；后者跳过已匹配、缺失文件和工程。卡片重试会覆盖其各份本地成员，保留标注。

## 浏览、搜索与整理

网格和列表共用搜索、多选、右键菜单及详情。内容密度、封面完整显示与界面缩放分别设置；切换视图保留选择，返回原筛选保留浏览位置。Shift 连续选择按当前结果顺序执行；方向键浏览，Ctrl+A 选择当前已显示结果，Ctrl+F 搜索，Esc 清除选择。编辑框与弹窗内不抢用这些快捷键。

集合只保存素材关联，同一素材可加入多个集合；移出或删除集合不删除素材。智能视图保存筛选条件并动态显示结果。标签可设置别名、合并及批量增删；撤销恢复本次标注变更，保留之后的联网信息。关闭后重新打开会保留集合、别名、视图偏好与标注。

搜索使用 SQLite FTS5 和本地字段索引；中文、日文短词、中英混排、文件名、编号、作者、标签及备注都纳入测试。多词默认共同匹配，准确商品编号优先；结果显示命中字段。适配筛选使用本地证据，普通关键词也可搜索商品支持的模型。派生索引可重建，原始记录与人工信息单独保存。异常记录保留原始内容并提示，不静默删除。能确认的同盘外部改名或移动保留记录身份；跨盘复制、多个硬链接等不凭猜测重绑定。

备份包含整理信息、集合、别名、设置、封面和恢复用异常记录，校验通过后才导入；不打包原素材。旧版备份兼容。图像预览范围与正文检索范围有明确限制：本版不提供视觉语义搜索、云端 AI、团队同步或完整工程依赖导出。

## 参考并应用的做法

- [TagSpaces 保存检索](https://docs.tagspaces.org/quick-access/)：智能视图与虚拟组织，不在原素材旁写标签文件。
- [TagSpaces 网格选择](https://docs.tagspaces.org/perspectives/grid/#selecting-files-and-folders)：按已筛选顺序连续多选。
- [Zotero 链接文件](https://www.zotero.org/support/attaching_files)：原位置引用与应用缓存分别管理。
- [KonoAsset](https://github.com/siloneco/KonoAsset) 与 [VRC Avatar Explorer](https://github.com/puk06/VRC-Avatar-Explorer)：商品编号、作者、本地路径和支持模型分别记录，推断信息保留来源。
- [SQLite FTS5](https://sqlite.org/fts5.html)：中文短词与混合文件名实测后采用组合索引。

## 可复验测试

`npm test` 使用临时测试目录，不写入用户素材。实际素材审计脚本为 `scripts/audit.cjs`：先运行建立源目录清单，再用 `--compare` 比较文件尺寸、修改时间及抽样哈希。测试运行数据保存在工作目录中，不属于可发布源码。

仅测试工具可使用以下环境变量建立独立资料库：`VRC_LIBRARY_DATA_DIR`、`VRC_LIBRARY_ROOT`、`VRC_LIBRARY_NO_NETWORK`、`VRC_LIBRARY_NO_AUTOSCAN`、`VRC_LIBRARY_TEST_HIDDEN`。显式测试数据目录覆盖允许使用隔离的 C 盘工作目录；正常界面选择禁止 C 盘。迁移 GUI 测试可使用 `VRC_LIBRARY_NO_RELAUNCH` 和 `VRC_LIBRARY_LOCATION_FILE`。正常运行不需要这些设置。
