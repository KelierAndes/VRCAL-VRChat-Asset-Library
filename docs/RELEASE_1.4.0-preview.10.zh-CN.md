# VRChat本地素材管理器 v1.4.0-preview.10

这次修复「待下载链接」中，闲鱼消息页已经显示会话，却仍提示“当前账号或交付区域未能确认”的情况，并让时间与读取状态更容易理解。

**验证范围：官网公开结构已核对，隔离合成 Chromium 链路已通过；实际闲鱼账号的新交付到下载全链路仍未验收。** 本版没有实现关闭平台窗口后的无人值守发现。

## 为什么之前看得到消息却读不到

旧读取器要求会话和消息具有明确的 ARIA 列表／日志标记。官网公开 `xy-site/0.0.179` 渲染的列表与正文主要使用普通 div，并不提供旧规则要求的这些标记。因此，即使本人账号栏已经识别，仍可能把消息区域判断为未支持。

本版根据官方公开脚本核对局部结构，补上对应规则。没有把读取范围扩大到整页，没有访问 Cookie、React 内部数据、其他浏览器或平台私有接口。登录状态不明时，也不会建议用户先清除账号。

## 怎样使用

1. 在应用左侧打开 **待下载链接**。
2. 如果还没有开启，勾选 **识别交付链接**，阅读并确认处理说明。登录和识别是两个独立选择；只登录不会自动同意读取。
3. 在 **闲鱼交付消息** 中点击 **登录／查看账号**，在官方窗口正常登录。
4. 要手动检查某条聊天，先在官方消息页打开该会话，再回应用点击 **检查新链接**。这个按钮读取当前打开会话，不会因为后台开关开启而改去只查侧栏摘要。
5. 符合范围的百度网盘链接出现在列表中。确认时间与来源后，点击 **选择文件下载**，继续读取分享、选择具体文件及保存位置。下载不是自动开始，也不自动下单。
6. 希望定时检查时，可另外开启 **后台检查（每 3 分钟）** 并确认相应范围。平台页面需要保持在应用内加载；后台开关和手动检查各自按自己的读取范围执行。

## 哪些内容会读取

| 情况 | 本版行为 |
| --- | --- |
| 当前已打开的闲鱼会话 | 只取受支持消息容器中的当条文字正文；剔除引用旧消息的子区域，不读取输入框草稿 |
| 后台检查 | 只检查已加载会话列表中有明确未读标记、唯一摘要及可核实近期时间的预览；排除被本地草稿替换的摘要 |
| 预览没有展示完整链接 | 不会自动进入该会话或翻页取得完整交付；可由用户打开会话后手动检查 |
| 账号切换、网址变化、关闭授权或取消 | 丢弃相应在途结果，不把不确定内容保存为交付 |
| 平台窗口全部关闭 | 不继续发现新内容；独立后台发现仍未完成 |
| BOOTH 已购资料库 | 保留已有局部读取；页面没有购买时间的商品只待核对，不推定近期购买 |

读取前后核对本人账号与官方网址，账号值转换为本地区分用散列。程序不发送消息、不主动点击未读会话，也不调用标记平台消息已读的操作；官网自身加载和显示行为仍由平台控制，不能保证隐身读取。

## 为什么时间前面会出现「约」

“2分钟前”表示一个时间区间，不是精确发送时间。本版保守地取这个显示区间的最早时刻：例如看到“2分钟前”，以本次检查前约 3 分钟作为判断依据，并在来源时间前标 **约**。小时、天采用同样规则，“刚刚”保守取约 1 分钟前。

“今天／昨天＋时分”也属于相对日期，同样标“约”，保留首次或更早的日期推定，不随跨日轮询漂移。同账号、同链接重复出现时，不因每次检查而一直变成新链接；之后取得明确的完整日期时间，可以替换近似值。已读、忽略和原发现时间不会因为重复读取而重置。

默认只看来源时间在最近 24 小时的交付，可改为 6／12 小时。只有 `12:34`、没有可靠日期的消息不当成今天；不能核实的时间只进入待核对，不点亮近期蓝点。明确几天前的链接不作为新交付。

## 现在会显示哪些状态

- **尚未确认本人账号栏**：账号信息或头像未能安全核对，等待加载，不代表账号一定退出。
- **账号已识别，但聊天结构尚未适配**：账号与消息结构分开判断，不再把所有问题都归到登录。
- **请先打开要检查的会话**：会话列表已经显示，但主区域还没有选中聊天。
- **当前未发现符合条件的链接**：已识别受支持区域，但未发现符合本次时间、未读和链接条件的内容；不等于账号识别失败。
