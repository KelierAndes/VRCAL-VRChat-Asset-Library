VRChat本地素材管理器 v1.4.0-preview.9

这次让 3D 预览更容易找到，并增加「角色＋衣服」静态组合参考，方便先看衣服的轮廓、款式和大致上身外观。

从哪里打开

  1. 在「全部素材」中点一下衣服卡片，打开右侧详情。
  2. 点击标题下面蓝色的 3D 预览；也可以右键卡片，选择 3D 预览。
  3. 如果素材内有多个模型，在窗口顶部 查看模型 中选择要看的 FBX、GLB、glTF 或 OBJ。
  4. 点击 添加角色看上身参考，选择已经登记到素材库的角色素材，再选择角色模型。只有一个模型时自动选中。

找不到角色时，先把角色原版模型文件夹拖入素材库。详细步骤及合成模型实机图见 3D 预览教程。右键选项可以在设置中隐藏或排序；已有偏好会保留。

可以怎样看

  • 单独看衣服，旋转、平移、拉近，切换前面、后面、左侧、右侧和立体视角。
  • 角色与衣服同时显示；可以单独隐藏衣服、角色，或隐藏角色模型中的原有衣服网格。
  • 手动调整衣服的缩放、XYZ 位置和旋转。修改只作用于当前画面，可恢复衣服原位。
  • 保持文件的原始坐标和单位，不按相同身高强行缩放。单位不同时，可手动尝试 0.01×、1× 或 100×，再精调。
  • 保留 25%–100% 渲染比例、素模、线框和亮度；组合预览关闭模型内置动画，避免误把独立动画当作衣服已绑定角色。

可靠性与读取范围

两个模型的资源分别管理，同名模型或贴图不串用；场景共用 300 万三角面、128 MiB 原始资源、128 MiB 贴图解码及 96 个文件上限。每个素材最多索引 16 个来源、200 个模型，索引总期限 45 秒。复杂素材可能无法在轻量预览中打开。

仅接受网格模型，混有点云、线条或精灵的模型会明确拒绝并释放资源；FBX 文件名中的特殊内嵌图片地址不支持，标准内嵌贴图继续按预算检查。

取消或读取失败保留上一次成功画面、手动调整和部件控件；迟到结果不覆盖当前选择。角色有多个模型时等待用户选择，不自动换成无角色画面。画面下方显示当前成功加载的模型名称，组合画面始终标明「静态组合 · 适配未验证」。

预览只读取用户选择的两个本地素材及其受支持依赖，不扫描整个资料库的模型、不写回原文件、不联网取得外部贴图、不调用 AI 或 Unity。

效果边界

这是静态外观参考。它不会自动把衣服骨骼绑定到角色，不还原 Unity 预制件、lilToon 等着色器、MA 装配、身体遮罩、A／T 姿势或物理效果；不提供自动体型适配、穿模检测或修复。只有 prefab、截图或贴图，不能凭空生成可旋转模型。RAR／7z 请先自行解压，再登记解压后的文件夹。

实际材质、适配、动作、菜单和穿模仍需在自己的 Unity 工程中验证。原版已支持的 FBX、GLB、glTF、OBJ、部分 ZIP／Unitypackage 读取继续保留。

升级与验证

退出旧程序，运行 VRC-Asset-Library-1.4.0-preview.9-x64.exe，继续使用原资料库，无需重新确认商品。本版是公开预览，需手动下载，不进入稳定更新通道。之前的 BOOTH 下载关联、网页 AI、匹配与整理功能继续保留；新增文字暂为中文。

本轮使用隔离资料库和自行生成的彩色角色／衣服，检查实际 Electron 像素、入口、显隐、调整、四主题、980px／200% 缩放、取消、权限与资源限制。未读取用户私有角色，不把合成模型组合称为真实商品适配通过。实际打包、完整回归、源文件哈希及 GitHub Windows CI 结果见发布附件中的验收记录。

发布附件包括免安装程序、对应提交的完整源码、中文指南、验收记录和 SHA-256，不含账号凭证、个人资料库或付费素材。
