## 更新和发布时

依赖升级后重新核对版本、锁文件摘要、版权人及全文；同名包的不同版本分别保留。`runtime-packages.json` 中的 `licenseSha256` 是对应许可正文原始字节的 SHA-256，`.gitattributes` 为这些正文禁用换行转换；`lockfileSha256` 按锁文件的 UTF-8 字节将 CRLF 统一为 LF 后计算，与 Git 中的版本一致；`packageIntegrity` 来自锁文件。除了 boolbase 的固定上游补充正文，其余运行包正文取自锁定版本的依赖包，未改写原作者声明。

现有 Electron Builder 配置收录 `licenses/**/*`、`THIRD_PARTY_NOTICES.md`、`NOTICE` 和字体目录；源码打包脚本也收录这些文件。发布时仍须核对实际成品是否带齐。仅更新仓库文档不会改写已经发布的安装包。

boolbase 1.0.0 的 npm 包未附独立许可文件；补充正文来自 [上游固定提交](https://github.com/fb55/boolbase/blob/be0bcd8a4e917a0a5895e95b523fbbed05a64871/LICENSE)。该提交的 package.json 标为 1.0.0，index.js 与本项目安装的副本字节一致。
